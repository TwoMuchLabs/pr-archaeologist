## How to use this file (for AI coding agents)

1. **Before editing a file, find its section**: search for the heading `### \`<path>\``.
2. Read **Past pitfalls** and **Why it exists**. If your change would undo a recorded fix or contradict a decision record, stop and say so instead of proceeding silently.

4. For more detail run `pr-archaeologist explain <path>` (add `--json` for structured output, `--function NAME` for one function).
